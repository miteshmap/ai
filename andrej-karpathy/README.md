# Karpathy-Inspired Claude Code Guidelines

This short guide collects prompt-engineering ideas and concise agent patterns inspired by Andrej Karpathy and adapted from the
[andrej-karpathy-skills repository](https://github.com/multica-ai/andrej-karpathy-skills).

Source & context
- Original repo (adapted): https://github.com/multica-ai/andrej-karpathy-skills
- Inspiration: [Andrej Karpathy's observations](https://x.com/karpathy/status/2015883857489522876)

Purpose
- Capture minimal, effective prompt patterns for Claude-style agents.
- Provide a place to iterate on small, composable skills and prompts.

Files
- `claude.md` — practical examples, prompt snippets, and short recipes (see this folder).

Usage notes
- Keep prompts short and testable: one intent per snippet.
- Add a brief example invocation and the expected concise output for each snippet.
- Where appropriate, note any setup or context required (tools, memory, or API keys).
